# Computer-Organization-and-Assembly-Language

Course materials for **DPI343 – Computer Organization and Assembly Language** at Riga Technical University (2025/26).

## Repository Structure
├── Lectures/           # Lecture materials (Topics 1–16)

└── Assignments/        # Individual practice assignments (A1–A6, A7 optional)

## Course Topics

| # | Topic |
|---|-------|
| 1 | Introduction, assembly program structure, tools |
| 2 | Registers, memory, arithmetic |
| 3 | Text processing, conversion |
| 4 | Library functions, Boolean operations |
| 5 | Loop instructions, string processing |
| 6 | Procedures, parameter passing |
| 7 | Interfacing with high-level languages |
| 8 | Interrupts & ISR |
| 9 | Timer interrupt, sound |
| 10 | Video output principles |
| 11 | Keyboard interrupt |

## Tech Stack

- **Language**: x86 Assembly (32-bit & 16-bit)
- **Tools**: Microsoft Visual Studio 2022, COAL Toolkit
- **Institution**: Riga Technical University
